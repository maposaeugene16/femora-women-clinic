# Femora Women’s Clinic — Led by Dr. Selena

A modern, high-performance website and healthcare service catalog for **Femora Women’s Clinic**, led by **Dr. Selena**, providing confidential women’s healthcare, fertility consultations, ultrasound scans, maternal wellness, menstrual & menopause care, and same-day discreet delivery across 17 nationwide locations in Zimbabwe.

Developed by **Maps**.

Built with **Next.js 16 (App Router)**, **React 19**, **TypeScript**, and **Tailwind CSS**. Fully static and serverless — requires no external database.

## Connecting to a New Git Repository

To ensure changes do **not** touch the original 1st system (`medication-website.git`), this project has been detached from that origin.

When you create your new GitHub repository (e.g. `femora-womens-clinic`):

```bash
# 1. Add your new repository remote
git remote add origin https://github.com/maposaeugene16/femora-womens-clinic.git

# 2. Stage and commit your changes
git add .
git commit -m "Femora Women's Clinic: Dr. Selena nationwide network & unique gallery showcase"

# 3. Push to your new repository
git push -u origin main
```

*(The original 1st system remains preserved at `aura-original`, untouched).*

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Environment Variables
Copy `.env.example` to `.env.local`:
```bash
cp .env.example .env.local
```

Configure:
```env
NEXT_PUBLIC_SITE_URL=https://femora-clinic.vercel.app
# Optional analytics
NEXT_PUBLIC_PLAUSIBLE_DOMAIN=
```

### 3. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build & Type Check
```bash
npm run typecheck
npm run build
```
